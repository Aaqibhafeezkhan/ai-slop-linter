# Fastq

Fastq is a job queue for Node. Version 2.3 processed 12,000 jobs per second on a single 4-core machine in benchmarks, 40% more than version 2.2. Maintainers at Acme Corp reported a 35% drop in p99 latency on their staging cluster. Fastq needs Node 20 or later and is released under the MIT license.

## Install

```sh
npm install fastq@2.3
```

See the [changelog](CHANGELOG.md) for details.
