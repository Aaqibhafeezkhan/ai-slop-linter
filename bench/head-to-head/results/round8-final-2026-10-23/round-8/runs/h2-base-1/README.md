# Fastq

Fastq is a job queue for Node.js backends. In our benchmarks, version 2.3 processed 12,000 jobs per second on a single 4-core machine, 40% faster than version 2.2. Maintainers at Acme Corp reported a 35% drop in p99 latency on their staging cluster. It requires Node 20 or later and is released under the MIT license.

## Install

```sh
npm install fastq@2.3
```

See the [changelog](CHANGELOG.md) for details.
