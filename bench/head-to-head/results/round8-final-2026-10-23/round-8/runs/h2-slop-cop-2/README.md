# Fastq

Fastq 2.3 is a job queue for Node.js. On a single 4-core machine it processes 12,000 jobs per second, 40% faster than version 2.2. Maintainers at Acme Corp reported a 35% drop in p99 latency on their staging cluster. It requires Node 20 or later and uses the MIT license.

## Install

```sh
npm install fastq@2.3
```

See the [changelog](CHANGELOG.md) for details.
