🚀 Je suis ravi d'annoncer la sortie de **Vérigo**, un nouveau lanceur de tests pour Python !

Pourquoi un énième outil de tests ? Parce que lancer sa suite ne devrait jamais être une corvée. Avec Vérigo, on se concentre sur l'essentiel : écrire du code fiable, et savoir rapidement s'il l'est.

✅ **Rapide** : découverte et exécution des tests en parallèle, pour des retours en quelques secondes.
✅ **Lisible** : des rapports clairs, des erreurs expliquées, fini les traces interminables.
✅ **Simple** : une installation en une commande, aucune configuration obligatoire pour démarrer.
✅ **Flexible** : compatible avec vos projets existants et facile à intégrer dans votre CI.

Vérigo est né d'un constat simple : plus un test est facile à lancer, plus on en écrit, et plus le code gagne en qualité.

Le projet est open source et nous serions heureux de recueillir vos retours, vos idées et vos contributions. 🙌
