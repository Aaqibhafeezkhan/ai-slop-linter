## Contribuer

Les contributions à Saule sont les bienvenues, qu'il s'agisse de corriger un bogue, d'améliorer la documentation, de proposer une fonctionnalité ou de traduire un message.

### Pour commencer

1. **Forkez** le dépôt, puis clonez votre copie en local.
2. Installez les dépendances et lancez la suite de tests pour vérifier que tout fonctionne.
3. Créez une branche dédiée à votre changement, avec un nom explicite (par exemple `fix-rendu-markdown`).

### Proposer une modification

- Pour un changement important, **ouvrez d'abord une issue** afin d'en discuter avec les mainteneurs avant d'investir du temps.
- Gardez vos *pull requests* **petites et ciblées** : une PR, un sujet.
- Ajoutez ou mettez à jour les **tests** correspondants, et assurez-vous qu'ils passent.
- Respectez le style du code existant et lancez le formateur avant de valider.
- Rédigez des messages de commit clairs, à l'impératif, par exemple : « Corrige le tri des articles par date ».
- Mettez à jour la documentation si le comportement change.

### Signaler un bogue

Indiquez la version de Saule, votre système, les étapes pour reproduire le problème, le résultat attendu et le résultat obtenu. Un exemple minimal de site qui reproduit l'erreur nous aide énormément.

### Code de conduite

Nous attendons de chacun un échange respectueux et bienveillant. Les relectures portent sur le code, jamais sur les personnes.

Merci de contribuer à faire pousser Saule 🌱
