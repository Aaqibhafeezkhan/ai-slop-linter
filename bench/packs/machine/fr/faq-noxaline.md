# FAQ Noxaline

**1. Qu'est-ce que Noxaline ?**
Noxaline est une application de relevé de compteurs d'eau conçue pour les gestionnaires d'immeubles. Elle remplace les carnets papier et les tableurs par un outil unique : vous relevez, vérifiez et exportez vos index depuis votre smartphone ou votre tablette.

**2. Comment fonctionne un relevé ?**
Sur place, vous photographiez le compteur ou saisissez l'index manuellement. Noxaline associe automatiquement la valeur au bon logement et signale les écarts anormaux, comme une consommation soudainement élevée pouvant révéler une fuite. Les relevés sont horodatés, ce qui limite les contestations.

**3. Puis-je relever les compteurs sans connexion internet ?**
Oui. Les caves et les locaux techniques captent rarement le réseau. Vous pouvez donc travailler hors ligne : les données sont enregistrées sur l'appareil, puis synchronisées dès que la connexion revient.

**4. Comment utiliser les données pour la facturation ?**
Vous exportez les consommations par logement, par bâtiment ou par période, au format Excel ou CSV. Ces fichiers se transmettent facilement à votre logiciel de gestion ou à votre comptable pour répartir les charges entre les occupants.

**5. Mes données sont-elles protégées ?**
Les données sont chiffrées pendant leur transfert comme à leur stockage, et hébergées au sein de l'Union européenne, conformément au RGPD. Vous définissez qui peut consulter ou modifier les relevés : gestionnaire, gardien ou prestataire extérieur, chacun avec ses propres droits d'accès.
