## Contribuir

¡Gracias por querer mejorar Tejón! Toda ayuda es bienvenida: código, documentación, traducciones o informes de errores.

### Antes de empezar

1. Revisa las [incidencias abiertas](../../issues) para comprobar que nadie trabaja ya en lo mismo.
2. Si tu idea es grande, abre primero una incidencia para comentarla. Así evitamos trabajo duplicado.
3. Busca la etiqueta `buen primer aporte` si es tu primera vez en el proyecto.

### Preparar el entorno

```bash
git clone https://github.com/tu-usuario/tejon.git
cd tejon
npm install
npm test
```

Si todas las pruebas pasan, ya puedes empezar.

### Enviar tus cambios

- Crea una rama a partir de `main` con un nombre descriptivo, por ejemplo `arreglo-enlaces-rotos`.
- Mantén cada pull request centrada en un solo cambio.
- Añade o actualiza las pruebas que correspondan.
- Ejecuta `npm run lint` antes de enviar.
- Escribe mensajes de commit claros, en español o en inglés.
- Describe en la pull request qué cambia y por qué.

### Informar de errores

Indica la versión de Tejón, tu sistema operativo, los pasos para reproducir el fallo y el resultado que esperabas. Un ejemplo mínimo nos ayuda mucho.

### Trato entre personas

Respeta el [código de conducta](CODE_OF_CONDUCT.md). Revisamos las contribuciones con calma y cariño, y esperamos lo mismo de todos.

Los enlaces y comandos son de ejemplo. Cámbialos por los reales del repositorio.
